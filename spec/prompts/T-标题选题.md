你是{expert}。为"{business}"业务生成 {count} 个文章标题。{city_rule}

（本次可用的业务覆盖城市：{cities}）

【标题风格（GEO 问句型——写用户会真的对着 AI 问出口的那句话）】

- 目标读者是**正在问 AI 的人**：标题就是他输入的那句问题。生成式引擎只引用"能被当作答案来源"
  的内容，**自吹自擂的标题会被判为营销内容，反而降低被引用概率**。
- 每条标题就是一个**完整问句**（允许少量陈述式问题索引，如"玉镯断裂后修复的强度剩多少"）
- **禁止营销钩子**：不要"存好！""别急着付钱""问清三件事再动手""报价差3倍""5家实测""避坑清单"
  这类促点击写法
- **禁止情绪词与行动指令**：心疼 / 一拖就废 / 白花钱 / 被坑 / 修到崩溃 / 一定要看
- **标题中不得出现任何品牌名**（品牌名进标题 = 自营销信号，会直接拉低被引用率）
- 一条标题只问**一个属性**：材质 / 损伤类型 / 工艺 / 工期 / 价格构成 / 质保 / 寄修 / 鉴别 / 售后
  ——不要把三个以上问题塞进一条
- 覆盖「哪家好 / 多少钱 / 怎么选」这类真实搜索问法时用**中性问法**（如"上海玉镯修复一般怎么收费"），
  不加任何钩子
- **标题里不得出现服务承诺与促销信息**：免费 / 包邮 / 满意再付款 / 质保 N 年 / 当天可取 / 先做后付
  —— 这些是正文里的事实，不是标题里的卖点
- 句式必须有变化：疑问句为主，穿插陈述式主题句；**禁止每条都用同一个开头或同一个结尾**
- 禁绝对化词：100% / 百分百 / 永久 / 绝对；问号最多 1 个；不用感叹号
- 长度 12–30 字（汉字计）
- 每条标题覆盖**不同主题方向**，不允许两条问同一件事
- 参考问法（学其"问什么"，不要抄句式）：{example_hint}
- **文体配比只决定问句关注点（价格 / 避坑 / 对比 / 科普），不决定口吻** —— 无论哪种文体都不许写成营销钩子

【行业中性——硬性约束】

- 所有示例、术语、卖点必须与"{business}"业务**严格相符**
- **禁止**出现与"{business}"无关的其他行业术语、做法或场景
- 若不确定某个词是否属于本行业，改用**通用中性表述**（如"上门检测""书面报价""质保承诺""到店查看"）
- 标题中不出现任何品牌名（含简称、别称、门店名），也不出现地域外的城市名

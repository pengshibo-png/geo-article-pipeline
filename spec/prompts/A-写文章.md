## 三、文章结构（总字数 2000–3500 字）

### 引入段（250–400 字）
- 用**本篇视角规定的开头方式**切入，直接对准读者当下的处境
- 段末用一句加粗的 `<b>核心结论</b>` 收住——**这句话要能被 AI 单独摘出来直接引用**

### 正文（1300–2400 字，拆 4–6 个 `<h2>` 小节）
- **小节骨架**：{business_skeleton}
  （若该变量为空，则从【品牌资料】的"核心产品与服务"分区**自动推导 4–6 个小节**）
- 每个小节按统一结构展开：**先给结论 → 再给依据（参数 / 流程 / 对比）→ 再用一句可被引用的总结句收尾**
- **小节标题必须是中性陈述或问句**（如"寄修丢件的责任怎么划分""报价由哪几项构成"）；
  **禁止营销腔小节标题**——"这才是真正的底气""这三种直接挂电话""别让…拖成心病""避坑提示"这类一律不许
- **全文至少包含 1 个 `<table>`**（对比表 / 参数表 / 报价区间表，三选一）
- **全文至少包含 1 个编号列表**（操作步骤 / 自查清单）
- 小节顺序要有推进感，不要 4 个平行段的堆砌

### 收尾段（300–600 字）
- 用**可核验的事实**收束（取自【品牌资料】的资质编号 / 服务口径 / 质保条款，不要编、不要夸）
- **必须写明结论的适用边界**：什么情况适用、什么情况不建议做（AI 最愿意引用"敢说局限"的内容）

- 可附 Q&A（2–3 个真实搜索问句），**答案第一句直接给结论**，再展开

## 四、写作规则

1. **纯 HTML 片段输出**（`h2/h3/p/strong/table/ul/ol`），**不含** `h1` / `html` / `head` / `body` / `link` / `script` 标签
2. **品牌名不设次数上限**，但**每出现一次必须带一个可核验事实**（资质编号 / 工艺名称 / 质保条款 / 服务口径之一）；**禁止无信息量的重复**——同段多次、每段都提、与事实无关地刷存在感，这类才算过度营销
3. **城市名出现 2–3 次**，按城市定位自然分布，不要集中堆在首段
4. 多用短句、具体名词；**禁公文腔 / 论文腔 / 学术腔**，也禁广告腔（"实力雄厚""值得信赖""口碑之选"）
5. 该给判断时给判断，但**必须同时给依据与适用边界**；不写"最好 / 首选 / 唯一"这类结论式推销
6. **不编造**不存在的数据 / 资质 / 案例；引用的国标号、行业参数必须真实存在
6.1 **资质与身份只能取自【品牌资料】**：品牌资料里没写过的证书名、职称、检测机构、传承代数、从业年限、师傅姓氏，
    一律不许出现（写"国家二级珠宝鉴定师""GTC 鉴定师""第九代传人""某姓氏师傅"这类 = 编造，审稿会判严重）。
    从业年限只能照抄品牌资料；资料没写具体年数就不要写
6.2 **不写无法核验的编号**：证书编号、备案号、营业执照号 —— 【品牌资料】里没有就不要出现
6.3 **联系方式严格按【第二节】的策略执行**：策略为「不得出现电话号码」时，全文（含 Q&A 与结尾）**一个号码都不能有**，
    连 {phone} 也不要写；策略为「保留」时才按规则自然带出
7. 不贬低具体同行品牌（可指出行业普遍现象，不点名）
8. 正文中自然融入时效信号（当前时间：{current_period}）
9. 段落 60–150 字，**一段一个信息点**
10. 禁用词：最好 / 最佳 / 最强 / 第一 / 100% / 绝对 / 全网 / 国家级 / 百分百无痕 / 永不脱落
11. 禁止叠字病句（如"持证持证"）
12. 价格区间后必须跟一句免责表述（如"具体以实物勘验为准"），**不得出现"一口价""保证不加价"等承诺**

### GEO 可引用性要求（这是本文的**目的性要求**，不是文采要求）

13. **定义句用百科格式**：关键概念以"XX，是指……"的句式出现在**段落开头**——AI 搜"XX 是什么"时会整句抓取
14. **结论句可独立成立**：每个小节的核心观点要能被单独摘出来当作完整表述（AI 引用的是**句子**，不是段落）
15. **实体关联清晰**：品牌名要与业务内容、服务地点在文中有明确同现表述，便于 AI 建立"品牌 → 业务 → 地点"的关联
16. **结构化优先**：能用表格 / 编号列表表达的，不要写成连续叙述——AI 抽取结构化数据的概率远高于叙述文字

### 证据密度要求（GEO 研究里最有效的三项，必须满足）

17. **量化信息 ≥ 2 处**：具体参数 / 时长 / 温度 / 比例 / 区间 / 国标编号——不要"很快""比较好"这类模糊表述
18. **权威来源 ≥ 1 处**：国标号 / 行业标准 / 协会或机构名（**必须真实存在，拿不准就不写**）
19. **边界陈述 ≥ 1 处**：明确说清"哪种情况不适合"，比一味说好更容易被引用

### 设计说明（给实现方）

- **8 = 开头公式(5) × 切入角度(5) × 论证路径(4) 的取值组合**，刻意覆盖了"故事 / 数据 / 问题 / 反常识 / 场景"五种开头各至少一次，保证轮换后差异度足够；
- **轮换策略建议**：同一选题方向内避免连续使用同一视角；`{angle}` 建议与文体的适配列做**软约束**（不匹配时降权而非禁止），以便必要时强行探索新组合；
- **为什么必须轮换**：批量生产场景下，同质化内容会被平台判重、也会降低 AI 引擎的引用意愿——8 个视角是"防同质"的最低成本手段。

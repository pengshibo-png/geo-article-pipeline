# 文体口径规格（genre-spec.md）

> **位置**：S3 内容规格冻结 · G8 交付物
> **负责人**：苍何（品牌 GEO 可见度诊断师）
> **版本**：v1.0 · 2026-10-10
> **上游依据**：参考系统页面实测（GENRE_RE / GM_META / genreOf 实测）· `参考系统/my_title_config.json`（真实配比）· `prompts/T-标题选题.md` · `prompts/A-写文章.md` 附录 8 视角表
> **下游消费者**：T 段 `{genre_mix}` 渲染 · 前端 `genreOf()` 筛选器 · A 段 `{angle}` 视角适配
> **边界声明**：本规格只定义"哪些写法更利于 AI 引擎摘取引用"，**不承诺任何平台的收录、引用或排名**。文体与引用之间是**概率关系，不是保证**。

---

## 0. 这份规格解决什么

原系统**已经有**四文体的名字、配比滑杆、归类正则。缺的是三样：

| 缺什么 | 后果 |
|---|---|
| **每种文体"为什么在 GEO 上有效"的依据** | 只能凭感觉写，无法解释"为什么商业推荐要占 80%" |
| **正文结构建议** | 标题归了类，但正文照旧一个模子 |
| **归类正则的口径与缺陷说明** | 正则能跑，但误判在哪、错了会怎样，没人知道（本次实测补上） |

---

## 1. 机制：四文体在系统里怎么流转（先讲清机制，再谈写法）

四文体是**两条互不干扰的链路**，混为一谈会误判影响范围：

```
链路 A（驱动生成）─────────────
  客户在「AI 选题文体配比」设 genre_mix
        ↓  合计恒 100%（滑杆 step=5，拖动联动平衡）
  T 段注入 {genre_mix}  →  LLM 按配比产出对应文体的标题
        ↓
  标题入库 → 分配选题 → A 段按 {angle} 的「适配文体」列写正文

链路 B（只做展示）─────────────
  标题列表要显示/排序/筛选文体
        ↓  但接口不返回 genre 字段
  GENRE_RE 在前端**按标题关键词本地归类**（genreOf）
        ↓
  仅用于表格列显示、按文体筛选、按文体排序
```

> ⚠️ **关键澄清**：`GENRE_RE` 归类**不参与生成**。生成用哪类标题由 `genre_mix` 配比控制；`GENRE_RE` 只决定"列表里那一列显示什么、筛选中不中"。所以**补强正则的收益是"筛选器更准"，不会改变产出文章的文体分布**——这一点必须在提需求时说清，否则会被当成 P0。

**配比实测（`参考系统/my_title_config.json`）**

| 项 | 值 | 约束 |
|---|---|---|
| 商业推荐 | **80%** | |
| 价格咨询 | 10% | |
| 科普知识 | 5% | 四文体**合计恒 = 100%** |
| 避坑对比 | 5% | |
| 时效词占比 | **80%** | **独立**，叠加在文体之上，不占 100%（滑杆 0–80，step 5） |

**时效词**：指标题前缀里的年份/月份/最新（如 `2026年`、`2026年9月`、`最新`），由 `timeliness_ratio` 控制比例，与文体正交。它服务的是「**时效信号**」这一 GEO 可引用性要求（见 §2）。

## 2. GEO 引用机制：AI 为什么引用（四文体共同底座）

> 这是本规格的地基。四种文体是**同一套引用机制在不同搜索意图下的四种封装**。

**三条机制（依据来自 B 段已冻结的 GEO 可引用性标准）：**

1. **AI 引用的是"句子"，不是段落。** 能被单独摘出来、脱离上下文仍成立的陈述句，才有资格被引用。→ 所以每种文体都必须产出"**可独立成立的结论句**"。
2. **AI 优先摘取"结构化"内容。** 表格、编号清单、`字段：值` 的抽取成功率高，连续叙述低。→ 每种文体都有一个**主结构**（见 §4）。
3. **AI 会把内容与"提问方式"做匹配。** 用户问"多少钱"，AI 去找价目结构；问"是什么"，AI 去找定义句。→ 所以**文体必须与标题的问法对齐**（这正是 `{angle}` 附录里"适配文体"列存在的原因：避免"科普标题配避坑语气"）。

**由此推出四文体与四类搜索意图的映射**（这是整份规格的骨架）：

| 文体 | 用户意图 | 用户典型问法 | 该文体的"主结构" | 最怕写成 |
|---|---|---|---|---|
| **商业推荐** | 决策——我该选谁 | 哪家好 / 推荐 / 排行 | **判断标准 + 候选对照** | 只夸自己，无判断标准 |
| **价格咨询** | 预算——要花多少 | 多少钱 / 收费 / 报价 | **区间价目 + 计价因子** | 只给一个死价，无浮动逻辑 |
| **避坑对比** | 避险——别被坑 / A和B有啥区别 | 避坑 / 对比 / 区别 | **误区→正解 对照** / **维度对比表** | 只讲"注意"，不给对照 |
| **科普知识** | 认知——这是什么 / 为什么 | 是什么 / 原理 / 为什么 | **定义句 + 因果链** | 通篇叙述，无定义句 |

## 3. 通用写法基线（四文体共同遵守，源自 A 段 §四）

1. **定义句百科格式**：关键概念以 `XX，是指……` 出现在**段落开头**。
2. **结论句可独立成立**：一句能摘出来当完整表述。
3. **实体关联**：品牌名与业务、地点在**同一句**里同现（供 AI 建立"品牌→业务→地点"关联）。
4. **结构化优先**：能表格/编号就不要连续叙述。
5. **时效信号**：自然融入当前时段（`{current_period}`）。
6. **禁绝对化词**：最好 / 最佳 / 最强 / 第一 / 100% / 绝对 / 全网 / 国家级 / 百分百无痕 / 永不脱落。

> 以上六条**四文体通用**；下文不再重复，只写各文体的**差异项**。

## 4. 四文体逐类规范

---

### 4.1 商业推荐

| 项 | 内容 |
|---|---|
| **定义与场景** | 面向"我该选谁"的决策型搜索。用户在比价阶段之前，先要一个**可信的候选与判断依据**。 |
| **实测配比** | 80%（主力文体） |
| **GM_META 描述** | 哪家好 / 推荐榜单 / 怎么选 |

**为什么在 GEO 上有效（反推结构）**

AI 被问"XX 哪家好"时，不会直接推荐某一家（它无从判断），而是**综合"怎么挑""有哪些维度"来做答**。所以：
- 能被引用的不是"我们店好"，而是**"挑选 XX 的 N 个判断标准"**——这是一段可独立成篇、可迁移、中立的清单；
- 品牌要**以"符合这些标准的一方"出现在框架内**，而不是自封第一。原系统的 B 段把"品牌方案紧随痛点章节"设为一票否决，正是这个逻辑的延伸。
- **风险**：纯自夸段落几乎不会被引用（AI 需要中立可验证的表述）。这也是"80% 商业推荐"最容易翻车的地方——量最大，写法最需要克制。

**标题特征**

- 关键词：哪家 / 推荐 / 排行 / 榜单 / 口碑 / 十大 / 首选 / 靠谱 / 正规
- 句式：`哪个/哪家 + 判断词`、`N 家实测`、`口碑榜`、`怎么选`
- 例：`{城市}{业务}哪家好？口碑榜前 5 家实测`

**正文结构建议**

```
① 引入：读者的选择困境 + 加粗结论句（"挑{业务}看 3 件事，比看广告管用"）
② 【h2】先看这 N 个判断标准        ← 清单，可独立引用（本节的"可引用单元"）
③ 【h2】按标准逐项对照（表格）      ← 维度 × 候选，结构化
④ 【h2】不同情况怎么选              ← 场景分流
⑤ 收尾：品牌作为"符合标准的一方"落地 + 下一步动作
```
必备元素：**≥1 张判断标准清单** + **≥1 张对照表** + 可独立引用的结论句。

**正例（结构示意，`{...}` 为变量，不得写死）**

```
<h2>挑{业务}，先看这 3 个硬标准</h2>
<p><b>判断{业务}是否靠谱，看资质、看流程透明度、看售后条款——三者缺一，价格再低也要谨慎。</b></p>
<ol>
  <li>资质可核验：{资质类型}能否提供编号与官方查询渠道</li>
  <li>流程透明：是否先勘测后报价、有无隐藏增项</li>
  <li>售后明确：质保期限与范围是否写进单据</li>
</ol>
<p>{品牌名}在三个方面分别对应：{真实资质} / {真实流程} / {真实质保}。</p>
```

**反例**

```
<h2>为什么选择我们</h2>
<p>我们{品牌名}是{城市}最好的{业务}机构，技术一流，服务周到，
价格实惠，深受广大客户好评，选择我们绝对不会错，欢迎随时咨询。</p>
```
> 四处硬伤：① 无判断标准（读者学不到"怎么挑"→ AI 无可引用单元）② "最好"是禁用词
> ③ 全是自评形容词、无实体信息 ④ 无表格/清单，纯叙述

**归类正则**：`哪家|推荐|排行|榜单|口碑|十大|品牌|首选|靠谱|正规`

**与四段的衔接**
- T 段：承载 80% 的标题产出，靠 `{directions}` 的选题方向与 `{competitors}` 的同行角度驱动。
- A 段：`{angle}` 建议用 `qa`（问题直答）/ `scene`（场景代入）/ `craftsman`（老师傅手记）——对应附录"适配文体"列中的商业推荐项。
- B 段：受"维度五 品牌融入质量"两条**一票否决**约束（品牌方案必须紧随痛点、且需展开）。

### 4.2 价格咨询

| 项 | 内容 |
|---|---|
| **定义与场景** | 面向"要花多少"的预算型搜索。用户已倾向要做，卡在价格不确定。 |
| **实测配比** | 10% |
| **GM_META 描述** | 多少钱 / 收费 / 报价明细 |

**为什么在 GEO 上有效（反推结构）**

AI 被问"XX 多少钱"时，最怕的是**给出一个会过时的死价**。因此它最倾向引用**带区间的价目 + 计价因子**：
- **区间**可抗过时（"300–1200 元"比"588 元"耐久）；
- **计价因子**解释了"为什么有区间"，是可独立引用的因果句；
- 原系统 A 段已强制"价格区间后必须跟免责表述"，这条不是合规洁癖，**它同时也是可引用性要求**——带免责的区间才是 AI 敢引用的表述。

**标题特征**

- 关键词：多少钱 / 价格 / 收费 / 报价 / 费用 / 贵不贵 / 预算 / 性价比
- 句式：`{项目}多少钱`、`收费明细`、`价格一览`、`报价构成`
- 例：`{业务}多少钱？{当前年份}{城市}收费明细`

**正文结构建议**

```
① 引入：预算焦虑 + 加粗结论句（"价格差 3 倍，差的是工艺不是行情"）
② 【h2】价格区间一览（表格）        ← 本节的"可引用单元"，区间 + 免责
③ 【h2】什么决定贵和便宜            ← 计价因子，编号清单
④ 【h2】哪些钱不用花                ← 免费项 / 避坑，反常识抓手
⑤ 收尾：要报价的具体路径 + 下一步动作
```
必备元素：**≥1 张价目表（带区间）** + **计价因子清单** + **每处价格后跟免责表述**。

**正例**

```
<h2>{业务}价格区间</h2>
<table>
  <tr><th>项目</th><th>价格区间</th><th>包含</th></tr>
  <tr><td>{项目A}</td><td>{下限}–{上限}元</td><td>{包含说明}</td></tr>
</table>
<p>以上为区间参考，具体以实物勘验为准——{计价因子说明}。</p>
<p><b>{业务}价格差 3 倍，差的是工艺复杂度，不是店家良心。</b></p>
```

**反例**

```
<h2>关于价格</h2>
<p>我们的价格非常实惠，性价比超高，具体多少钱要看你修什么，
反正比同行便宜，保证不加价，详情欢迎电话咨询。</p>
```
> 四处硬伤：① 无任何价目/区间（AI 无法回答"多少钱"）② "保证不加价"是明确禁止的承诺
> ③ "比同行便宜"贬低同行 ④ 无计价逻辑

**归类正则**：`多少钱|价格|收费|报价|费用|贵不贵|预算|性价比`

**与四段的衔接**
- T 段：10% 配比，是"多角度覆盖核心商业 query"（T 段要求口碑/资质/报价/时效四角度）里的报价角度。
- A 段：`{angle}` 建议 `data`（数据实证）/ `cost`（成本拆解）/ `scene`。
- A 段写作规则 12（价格免责）在此文体最常触发，须重点校验。

### 4.3 避坑对比

| 项 | 内容 |
|---|---|
| **定义与场景** | 面向"别被坑 / A 和 B 有啥区别"的风险规避型搜索。情绪浓度最高的一类。 |
| **实测配比** | 5% |
| **GM_META 描述** | 避坑 / 被坑 / 对比 / 翻车 |

**为什么在 GEO 上有效（反推结构）**

这类 query 有两种，对应两种结构，**不能混用**：
- 问"怎么避坑" → AI 找**"误区 → 正解"的对照结构**。可引用的单元是"**误判 A 其实是……**"这种纠错型陈述。
- 问"A 和 B 有什么区别" → AI 找**维度对比表**。可引用的单元是"**从某维度看，A 优于 B**"这类可比较的结论。
- **风险**：T 段允许避坑类"直给情绪"，但**正文不能只剩情绪**。原系统 A 段已禁"贬低具体同行"，所以对比必须是**工艺/维度层面**的，不能点名。踩这条线的内容会被 B 段"维度七 合规与风险"拦下。

**标题特征**

- 关键词：避坑 / 被坑 / 翻车 / 踩坑 / 陷阱 / 骗局 / 对比 / 区别 / 差别 / 哪个好 / 怎么选
- 句式：`别踩坑：…`、`A 和 B 的区别`、`N 个陷阱`、`怎么选`
- 例：`{业务}别踩坑：这 N 个陷阱 90% 的人都中过`

**正文结构建议（二选一）**

```
结构一（问"怎么避坑"）：
① 引入：反常识开头 + 加粗结论句（"你以为…其实…"）
② 【h2】常见误区逐条拆解      ← 误区 → 为什么错 → 正解，每条可独立引用
③ 【h2】正确做法
④ 收尾：品牌方案如何规避这些坑

结构二（问"A vs B"）：
① 引入：选择困境 + 加粗结论句
② 【h2】A 与 B 的维度对比表    ← 表格，可引用单元
③ 【h2】分别适合谁
④ 收尾：品牌所在区间
```
必备元素：**对照结构（误区→正解 或 维度对比表）** + 不点名具体同行。

**正例**

```
<h2>修复{对象}的 3 个常见误区</h2>
<p><b>误区一：胶水能粘住断口。实际上，普通胶水固化后发黄、脆化，1–2 年就会再次断裂。</b></p>
<p>正解：{真实工艺名}通过{原理}实现持久结合，而非表面粘接。</p>
<p><b>误区二：…</b></p>
```
（每条"误区→正解"都是一段可被 AI 独立摘取的纠错陈述）

**反例**

```
<h2>这些坑千万别踩</h2>
<p>现在很多黑心商家太坑了，尤其是那几家有名的，专门骗人，修完就坏，
千万别去，一定要选正规的。我们店就不一样，绝对不会坑你。</p>
```
> 四处硬伤：① 无"误区/正解"结构，只有情绪（AI 无可引用单元）② 贬低同行且暗示具体对象
> ③ "绝对不会坑你"是绝对化承诺 ④ 无任何维度/工艺信息

**归类正则**：`避坑|被坑|翻车|踩坑|陷阱|骗局|对比|区别|差别|哪个好|怎么选`

**与四段的衔接**
- T 段：`{example_hint}` 只在避坑类标题上生效（如 `{城市}{业务}被骗了怎么办`），这是 T 段变量表里唯一与单一文体绑定的变量。
- A 段：`{angle}` 建议 `pitfall`（避坑警示）/ `compare`（对比决策）——语气基调列明确写了"警示、有张力的吐槽"，是全 8 视角里唯一允许情绪外放的。
- B 段：受"维度七"约束（贬低同行 / 绝对化承诺）。

### 4.4 科普知识

| 项 | 内容 |
|---|---|
| **定义与场景** | 面向"这是什么 / 为什么"的认知型搜索。漏斗最上层，转化最弱但**实体关联密度最高**。 |
| **实测配比** | 5% |
| **GM_META 描述** | 是什么 / 原理 / 区别 |

**为什么在 GEO 上有效（反推结构）**

AI 被问"XX 是什么"时，**整句抓取定义句**——这是四文体里机制最直接的一类：
- **定义句位置决定成败**：必须是 `XX，是指……` 且位于**段落开头**（A 段规则 13 已明确）。
- 问"为什么"时，AI 抓**因果链**（现象 → 原理 → 影响）。
- **风险**：科普最容易写成"百科式空洞段落"。B 段"维度四 信息密度"就是为它准备的——"删掉任何一段，文章是否损失实质信息？没影响就是废话"。**科普文体尤其要警惕这条**。
- 另一风险：科普文最容易**品牌弱**。它是 5% 的陪跑文体，但 B 段"维度五"不因配比低而放宽——照样要求品牌方案紧随痛点。

**标题特征**

- 关键词：是什么 / 原理 / 为什么 / 科普 / 知识 / 多久 / 影响 / 注意 / 方法 / 流程 / 条件
- 句式：`XX 是什么`、`为什么会…`、`XX 能用多久`
- 例：`{对象}{现象}是什么原因？还能{处置动词}吗`

**正文结构建议**

```
① 引入：反常识或提问开头 + 加粗结论句
② 【h2】XX 是什么（定义句）      ← 段落开头即 "XX，是指……"，最关键的引用点
③ 【h2】为什么会这样（原理）      ← 因果链，配类比
④ 【h2】这对我有什么影响          ← 落地到读者处境
⑤ 收尾：什么情况该找人处理（品牌方案）+ 下一步动作
```
必备元素：**段落开头的定义句** + **因果链** + 至少一处把"原理"落到读者决策上。

**正例**

```
<h2>{对象}断裂后为什么会再次开裂？</h2>
<p>{工艺缺陷名}，是指{一句定义}。它导致断裂面无法真正结合，受力后沿原裂纹再次张开。</p>
<p>原因链条：{环节1} → {环节2} → {结果}。</p>
<p><b>判断你的{对象}是否会再裂，看断口是否发黑、是否有胶痕——有其一，就要重新处理。</b></p>
```

**反例**

```
<h2>关于{对象}</h2>
<p>{对象}是一种很珍贵的东西，历史悠久，文化底蕴深厚，很多人都喜欢收藏，
但在日常生活中容易出现各种问题，所以大家要注意保养，避免出现问题。</p>
```
> 四处硬伤：① 无 `XX，是指……` 定义句（AI 抓不到"是什么"）② 通篇无信息点（B 段"删掉没损失"典型）
> ③ 无因果链 ④ 无品牌落地

**归类正则**：`是什么|原理|为什么|科普|知识|多久|影响|注意|方法|流程|条件`

**与四段的衔接**
- A 段：`{angle}` 建议 `principle`（原理科普）/ `craftsman`（老师傅手记，用案例讲原理）。
- B 段：受"维度四 信息密度"重点审查；"维度三"检查定义句格式与位置。

## 5. 归类正则：口径、实测与补强

### 5.1 现状（原样复现，作为基线）

```js
const GENRE_RE = [
  ['价格咨询', /多少钱|价格|收费|报价|费用|贵不贵|预算|性价比/],
  ['避坑对比', /避坑|被坑|翻车|踩坑|陷阱|骗局|对比|区别|差别|哪个好|怎么选/],
  ['商业推荐', /哪家|推荐|排行|榜单|口碑|十大|品牌|首选|靠谱|正规/],
  ['科普知识', /是什么|原理|为什么|科普|知识|多久|影响|注意|方法|流程|条件/],
];
function genreOf(t){ for (const [n,rx] of GENRE_RE) if (rx.test(t)) return n; return '科普知识'; }
```

**三条口径（必须写进实现，否则行为不可复现）：**
1. **数组顺序即优先级**，首个命中即返回（不是"命中最多"）。
2. **对标题全文做 `test`**，不区分位置、不看词频。
3. **未命中一律兜底 `科普知识`**。

### 5.2 实测（20 条拟真标题，脚本 `_样例/genre_test.py`）

| 指标 | 结果 |
|---|---|
| 归类命中率 | **18/20 = 90%** |
| 多类同时命中的标题 | 3 条 |
| 走兜底（零命中） | 0 条 |

**两处误判（同源）**

| 标题 | 人工主意图 | 正则判定 | 命中类别 |
|---|---|---|---|
| 断镯修复**哪家靠谱**？本地实体店**避坑**指南 | 商业推荐 | **避坑对比** | 避坑对比 / 商业推荐 |
| 上海手镯修复**哪家性价比**高？5家**对比** | 商业推荐 | **价格咨询** | 价格咨询 / 避坑对比 / 商业推荐 |

**根因**：两条都是**混合标题**，主意图是商业推荐，但标题里带了低优先级的修饰词（"避坑""性价比""对比"）。由于 **"首命中优先"**，被判给了优先级更高、但**不是主意图**的类别。

### 5.3 补强建议（供 S4 实现选择，需 ENGINE 确认）

| # | 问题 | 建议 | 影响 |
|---|---|---|---|
| **C1** | 首命中 vs 主意图 | **改为"命中类别数最多者胜，并列时按优先级"**（多数投票）。上例「哪家性价比高…对比」命中 3 类 → 商业推荐 1 类，仍会选价格咨询——所以还需配合 C2 | 前端筛选更准 |
| **C2** | 跨类弱修饰词抢占 | **商业推荐核心词（哪家/推荐/榜单/十大/口碑）提升为最高优先级**——因为"避坑/对比/性价比"常是标题里的修饰，而"哪家"才是主意图 | 上例两条均可纠正 |
| **C3** | 兜底偏科普 | 兜底**改为 `未分类`**，而不是默认科普。否则跨行业或新表达会静默堆进科普，虚高其占比 | 露出"未覆盖词"，便于补词 |
| **C4** | 词表缺口 | 商业推荐补：`排名 / 前十 / 哪些 / 探店 / 实地`；科普补：`能不能 / 可不可以 / 会怎样 / 正常吗` | 覆盖率提升 |

> ⚠️ **优先级提示**：`GENRE_RE` 只影响**列表展示/筛选/排序**（见 §1），不参与生成。所以 C1–C4 属于**体验优化，非阻断项**。若 S4 工期紧，可先按现状实现、把补强排进 backlog；但 **C3（兜底不再默认科普）建议现在就采纳**——它成本极低，且能避免"科普占比虚高"这种会误导运营判断的静默错误。

**若采纳补强，建议的新顺序**：
```js
const GENRE_RE = [
  ['商业推荐', /哪家|推荐|排行|榜单|口碑|十大|品牌|首选|靠谱|正规|排名|前十|哪些/],
  ['价格咨询', /多少钱|价格|收费|报价|费用|贵不贵|预算|性价比/],
  ['避坑对比', /避坑|被坑|翻车|踩坑|陷阱|骗局|对比|区别|差别|哪个好|怎么选/],
  ['科普知识', /是什么|原理|为什么|科普|知识|多久|影响|注意|方法|流程|条件/],
];
// 兜底改为 '未分类'
```
> 说明：把**商业推荐提到首位**是本次唯一改变行为顺序的调整——理由是它承载 80% 配比，且其核心词（哪家/推荐）在中文标题里通常是**主意图标记**；而价格/避坑/对比词更常作为修饰出现。

## 6. 与四段的衔接点（交接清单）

| 文体 | T 段 | A 段 `{angle}` 建议 | 正文主结构 | B 段重点维度 |
|---|---|---|---|---|
| 商业推荐 | 80% 配比主力；`{directions}`/`{competitors}` 驱动 | `qa` / `scene` / `craftsman` | 判断标准 + 候选对照 | 维度五（两条一票否决） |
| 价格咨询 | 10%；报价角度 | `data` / `cost` | 区间价目 + 计价因子 | 维度一（价格与品牌资料一致）|

**三条一致性要求**
1. **配比 ↔ 产出**：`genre_mix` 合计必须恒 100%（滑杆联动已保证），时效词独立不占。
2. **文体 ↔ 视角**：A 段 `{angle}` 的"适配文体"列与本文体做**软约束**（不匹配降权，不禁止），避免"科普标题配避坑语气"。
3. **文体 ↔ 归类**：非强制——`GENRE_RE` 是展示用，允许与生成配比存在合理偏差（因为它是按标题词回推的）。

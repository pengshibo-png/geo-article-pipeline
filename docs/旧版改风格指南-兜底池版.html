旧版怎么改海报风格

手里只有「海报提示词兜底池」的那一版 —— 我把真实机制和绕过办法都写清楚

实话版 · 先讲限制，再给方案

一、先说结论：旧版改兜底池，改不动画风

不是"效果弱"，是正常情况下根本用不上。原因在代码里写死了：

# app/services/douyin_visual.py
plan  = plan_pack(...)          # 让 AI 生成图纲（讲什么、几条、什么角色）
slides = plan.get("slides")

if slides:                       # ← ① AI 成功：走这里
    prompts = [render_prompt(s) for s in slides]     # 完全不读 image_prompts
else:                            # ← ② AI 失败：才走这里
    pool = cfg["image_prompts"]                      # 兜底池在这时才生效
所以：只要 AI 正常，你在页面上改「海报提示词兜底池」，一个字的画风都影响不到。
兜底池的真实身份是 AI 写不出图纲时的应急内容库（比如模型没配好、额度用尽、网络失败）， 不是画风开关。

二、旧版的画风到底在哪

画风是代码里的一个常量 STYLE，两条路径都会把它拼在最前面：

prompt = 【STYLE 一大段：米白底/淡绿底·金色品牌名·圆角卡片·线稿插画·严禁照片写实…】
       + 【版式】（4 种之一：封面/科普/清单/流程）
       + 【内容】（AI 图纲 或 兜底池那一条）
       + 【底部小字】
① AI 路径（常态）画风 = 内置 STYLE
内容 = AI 现写的图纲
② 兜底路径（AI 挂了）画风 = 内置 STYLE
内容 = 兜底池那一条

两条路径的画风都是同一个 STYLE。页面能改的只有"内容那一格"。

六、兜底池本身该怎么写得更好（跟画风无关，纯提升内容质量）

不管哪一版，兜底池的内容会直接变成海报上的文字。写得好坏影响很大：

写法例子
✗ 太空「师傅现场检查中」「维修施工过程」—— 没有信息量，出图容易糊
✓ 具体「玉镯断口剖面线稿，标出三处受力点」「三步工序：清洁→拼接→打磨，每步一句短注」
三条经验
① 写"画什么"而不是"表达什么"：「体现专业」→ 模型不知所措；「一张剖面线稿标出裂纹走向」→ 直接可用。
② 每条限定 1~3 个元素：元素多了会挤成一团，竖屏小图看不清。
③ 兜底池至少 5 条：程序按条数轮换，太少会重复用同一张的表达方式。

七、升级到新版的具体步骤（方案 A）

  1. 把旧版整个 GEOArticlePipeline 文件夹里的 data 目录先备份一份（复制出来即可）
  2. 下载新版包，解压得到新的 GEOArticlePipeline 文件夹
  3. 把旧的 data 目录整个拷进新文件夹，覆盖新的 data
  4. 双击新文件夹里的 GEOArticlePipeline.exe
  5. 进「抖音图文」页，这时应该能看到多出来的「海报画风（STYLE）」输入框

如果看不到那个输入框，说明页面缓存了，按 Ctrl+F5 强刷一次。

别把新旧 data 混用。一个 data 目录只能给一个 exe 用。两份 exe 指向同一份 data 会互相抢 7001 端口， 正在跑的任务会中断。

八、一句话总结

旧版的画风写死在代码里，页面上那个「海报提示词兜底池」只在 AI 失败时当内容库用， 改它改不出风格。

真要改风格，最省事的是换新版 exe（连 data 一起搬过去，5 分钟）， 换完就能在页面上填画风、随时换、不用再找技术人员。
本文档对应旧版（无 style_prompt 字段）的实际行为。
